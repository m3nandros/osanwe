# Настройка приватного хранилища для конфиденциальных PDF

## Проблема безопасности

Публичные временные хранилища (file.io, transfer.sh, 0x0.st) создают **публичные URL**, которые может скачать **любой, у кого есть ссылка**. Это небезопасно для конфиденциальных документов.

## Решение: AWS S3 с приватными bucket'ами

### Шаг 1: Создание AWS аккаунта и S3 bucket

1. Зарегистрируйтесь на [AWS](https://aws.amazon.com/)
2. Перейдите в [S3 Console](https://console.aws.amazon.com/s3/)
3. Создайте новый bucket:
   - Название: например, `rosetta-pdfs-private`
   - Регион: выберите ближайший (например, `us-east-1`)
   - **ВАЖНО**: Отключите "Block all public access" (bucket должен быть приватным)

### Шаг 2: Создание IAM пользователя и ключей

1. Перейдите в [IAM Console](https://console.aws.amazon.com/iam/)
2. Создайте нового пользователя:
   - Имя: `rosetta-s3-uploader`
   - Тип доступа: Programmatic access
3. Прикрепите политику (Policy):
   ```json
   {
     "Version": "2012-10-17",
     "Statement": [
       {
         "Effect": "Allow",
         "Action": [
           "s3:PutObject",
           "s3:GetObject",
           "s3:DeleteObject"
         ],
         "Resource": "arn:aws:s3:::your-bucket-name/*"
       }
     ]
   }
   ```
   Замените `your-bucket-name` на имя вашего bucket'а.
4. Сохраните Access Key ID и Secret Access Key

### Шаг 3: Установка boto3

```bash
pip install boto3
```

### Шаг 4: Настройка .env файла

Добавьте в ваш `.env` файл:

```bash
# Стратегия загрузки файлов
NOTION_FILE_UPLOAD_STRATEGY=temporary

# Приватное хранилище AWS S3
NOTION_TEMP_STORAGE=s3

# AWS S3 настройки
AWS_ACCESS_KEY_ID=your_access_key_here
AWS_SECRET_ACCESS_KEY=your_secret_key_here
AWS_S3_BUCKET=your-bucket-name
AWS_S3_REGION=us-east-1
AWS_S3_PRESIGNED_URL_EXPIRY=604800  # 7 дней в секундах (можно увеличить)
```

### Шаг 5: Проверка работы

После настройки, при следующем переводе статьи:
1. PDF файлы будут загружены в ваш приватный S3 bucket
2. В Notion будут созданы presigned URL (временные приватные ссылки)
3. Ссылки будут работать только ограниченное время (по умолчанию 7 дней)
4. Файлы **недоступны** без presigned URL

## Безопасность

### Что обеспечивает это решение:

✅ **Приватное хранение**: Файлы хранятся в приватном S3 bucket, недоступны публично

✅ **Временные ссылки**: Presigned URL истекают через заданное время (по умолчанию 7 дней)

✅ **Контроль доступа**: Только ваш бот может загружать файлы (через IAM ключи)

✅ **Политики доступа**: Можно настроить дополнительные политики на уровне bucket

### Дополнительные меры безопасности:

1. **Настройте lifecycle policy** для автоматического удаления старых файлов:
   - В S3 Console → ваш bucket → Management → Lifecycle rules
   - Создайте правило для удаления файлов старше 30 дней

2. **Включите логирование** для отслеживания доступа:
   - В S3 Console → ваш bucket → Properties → Server access logging

3. **Используйте шифрование**:
   - В S3 Console → ваш bucket → Properties → Default encryption
   - Включите AES-256 или AWS-KMS шифрование

## Альтернатива: Локальное хранение

Если вы не хотите использовать AWS S3, можно использовать локальное хранение:

```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=local
```

В этом случае:
- Файлы **не загружаются** в публичные хранилища
- В Notion создается текстовая ссылка на локальный файл
- Файлы остаются на вашем сервере
- Доступ только через ваш сервер/бот

⚠️ **Ограничение**: Файлы будут доступны только если у вас есть доступ к серверу, где они хранятся.

## Стоимость AWS S3

AWS S3 очень дешевый для небольших объемов:
- Хранение: ~$0.023 за GB/месяц
- Загрузка: ~$0.005 за 1000 запросов
- Скачивание: ~$0.09 за GB (первые 10 TB)

Для 100 PDF файлов по 5 MB каждый:
- Хранение: ~$0.01/месяц
- Загрузка: ~$0.001
- Скачивание: зависит от использования

**Первый год**: AWS предоставляет бесплатный tier (5 GB хранения, 20,000 запросов)

## Troubleshooting

### Ошибка: "AWS S3 credentials not configured"
- Проверьте, что все переменные AWS_* установлены в .env
- Убедитесь, что .env файл загружается правильно

### Ошибка: "boto3 not installed"
```bash
pip install boto3
```

### Ошибка: "Access Denied"
- Проверьте, что IAM пользователь имеет права на bucket
- Проверьте, что bucket существует и имя правильное
- Проверьте, что регион (AWS_S3_REGION) правильный

### Файлы не отображаются в Notion
- Проверьте логи - возможно, presigned URL не генерируется
- Убедитесь, что bucket приватный (не публичный)
- Проверьте срок действия presigned URL (может быть слишком коротким)
