# Настройка постоянного хранилища для долгосрочного доступа (10+ лет)

## Проблема

Для долгосрочного хранения (10+ лет) нужны **постоянные URL**, которые не истекают. Временные хранилища и presigned URL не подходят.

## Решения для долгосрочного хранения

### 1. AWS S3 с публичными URL (РЕКОМЕНДУЕТСЯ) ⭐

**Преимущества:**
- ✅ Постоянные URL (не истекают)
- ✅ Высокая надежность (99.999999999% durability)
- ✅ Низкая стоимость (~$0.023/GB/месяц)
- ✅ Масштабируемость
- ✅ Можно настроить CDN для быстрого доступа

**Настройка:**

1. Создайте S3 bucket с публичным доступом на чтение:
   ```bash
   # В AWS Console:
   # - Создайте bucket
   # - Отключите "Block all public access"
   # - Включите "Public read access" для bucket policy
   ```

2. Добавьте в `.env`:
   ```bash
   NOTION_FILE_UPLOAD_STRATEGY=temporary
   NOTION_TEMP_STORAGE=s3_public
   
   AWS_ACCESS_KEY_ID=your_access_key
   AWS_SECRET_ACCESS_KEY=your_secret_key
   AWS_S3_BUCKET=your-bucket-name
   AWS_S3_REGION=us-east-1
   ```

3. Установите boto3:
   ```bash
   pip install boto3
   ```

**Безопасность:**
- ⚠️ Файлы будут публично доступны по URL
- ✅ Можно ограничить доступ через bucket policy (только для вашей команды)
- ✅ Можно использовать CloudFront с авторизацией

### 2. Постоянное локальное хранилище с веб-сервером

**Преимущества:**
- ✅ Полный контроль над файлами
- ✅ Нет зависимости от внешних сервисов
- ✅ Можно настроить авторизацию
- ✅ Файлы хранятся локально

**Настройка:**

1. Настройте веб-сервер (nginx/apache) для обслуживания файлов:
   ```nginx
   # nginx example
   server {
       listen 80;
       server_name files.yourdomain.com;
       
       location /permanent_storage/ {
           alias /path/to/permanent_storage/;
           add_header Content-Disposition "inline";
       }
   }
   ```

2. Добавьте в `.env`:
   ```bash
   NOTION_FILE_UPLOAD_STRATEGY=temporary
   NOTION_TEMP_STORAGE=permanent
   
   PERMANENT_STORAGE_DIR=./permanent_storage
   PERMANENT_STORAGE_URL_BASE=https://files.yourdomain.com/permanent_storage
   ```

3. Убедитесь, что директория существует:
   ```bash
   mkdir -p permanent_storage
   ```

**Структура файлов:**
```
permanent_storage/
  └── 1706.03762/
      ├── original_1706.03762.pdf
      └── translated_1706.03762.pdf
```

**Безопасность:**
- ✅ Файлы хранятся локально
- ✅ Можно настроить авторизацию на уровне веб-сервера
- ✅ Полный контроль над доступом

### 3. Google Drive / Dropbox (альтернатива)

Можно использовать Google Drive или Dropbox API для загрузки файлов и получения постоянных ссылок. Требует OAuth авторизацию.

## Рекомендации для долгосрочного хранения

### Для команды (10+ лет доступа):

**Вариант 1: AWS S3 с публичными URL (лучший баланс)**
```bash
NOTION_TEMP_STORAGE=s3_public
```

**Вариант 2: Локальное хранилище с веб-сервером (полный контроль)**
```bash
NOTION_TEMP_STORAGE=permanent
PERMANENT_STORAGE_URL_BASE=https://files.yourdomain.com/permanent_storage
```

### Обеспечение долгосрочной доступности:

1. **Резервное копирование:**
   - Настройте автоматическое резервное копирование S3 bucket
   - Или синхронизируйте локальное хранилище с другим сервером

2. **Мониторинг:**
   - Настройте алерты на доступность файлов
   - Регулярно проверяйте работоспособность URL

3. **Документация:**
   - Документируйте структуру хранения
   - Сохраняйте информацию о доступе к хранилищу

## Стоимость AWS S3 для долгосрочного хранения

Для 1000 PDF файлов по 5 MB каждый (5 GB):
- **Хранение**: ~$0.12/месяц (~$1.44/год)
- **Запросы**: ~$0.01/месяц
- **Передача данных**: зависит от использования

**За 10 лет**: ~$15-20 (при минимальном использовании)

## Миграция существующих файлов

Если у вас уже есть файлы во временном хранилище:

1. Скачайте все файлы
2. Загрузите их в постоянное хранилище (S3 или локальное)
3. Обновите URL в Notion (можно автоматизировать через скрипт)

## Troubleshooting

### AWS S3: "Access Denied" при доступе к файлам
- Проверьте bucket policy - должен разрешать публичный доступ на чтение
- Проверьте ACL файлов - должны быть `public-read`

### Локальное хранилище: URL не работают
- Проверьте, что веб-сервер запущен
- Проверьте, что PERMANENT_STORAGE_URL_BASE правильный
- Проверьте права доступа к файлам

### Файлы не отображаются в Notion
- Проверьте логи - возможно, URL не генерируется
- Убедитесь, что URL доступны из интернета
- Проверьте формат URL (должен начинаться с http:// или https://)
