# Лимиты Notion по тарифам для загрузки файлов через API

## Важная информация

API `v1/file_uploads` доступен на **всех планах Notion**, включая бесплатный, но с разными лимитами.

## Лимиты по тарифам

### Free Plan (Бесплатный)

- ✅ **API доступен**: Да
- 📦 **Лимит размера файла**: **5 MB** на один файл
- 📊 **Лимит хранилища**: 
  - Неограниченное количество файлов
  - Но если в workspace > 1 участника: лимит **1000 блоков** (файлы считаются блоками)
- 💰 **Стоимость**: Бесплатно

**Что это значит**: Файлы до 5 MB можно загружать напрямую в Notion. Файлы больше 5 MB будут автоматически использовать внешнее хранилище.

### Paid Plans (Plus, Business, Enterprise)

- ✅ **API доступен**: Да
- 📦 **Лимит размера файла**: **До 5 GB** на один файл
- 📊 **Лимит хранилища**: Практически неограниченный
- 💰 **Стоимость**: 
  - Plus: $10/мес (при оплате за год)
  - Business: $18/мес (при оплате за год)
  - Enterprise: индивидуально

**Что это значит**: Можно загружать файлы до 5 GB напрямую в Notion.

## Настройка в системе

### Для Free Plan (рекомендуется):

```bash
# Используйте лимит 5 MB (по умолчанию)
NOTION_DIRECT_UPLOAD_LIMIT_MB=5.0
```

### Для Paid Plans:

```bash
# Можно увеличить лимит (в MB)
NOTION_DIRECT_UPLOAD_LIMIT_MB=100.0   # 100 MB
NOTION_DIRECT_UPLOAD_LIMIT_MB=1000.0  # 1 GB
NOTION_DIRECT_UPLOAD_LIMIT_MB=5000.0  # 5 GB (максимум)
```

## Как система обрабатывает файлы

### Автоматический выбор метода:

1. **Файл ≤ лимита** (5 MB для Free, до 5 GB для Paid):
   - ✅ Прямая загрузка в Notion через API
   - Файл хранится на серверах Notion
   - Долгосрочный доступ (10+ лет)
   - Подчиняется правам доступа страницы

2. **Файл > лимита**:
   - ✅ Автоматический fallback на внешнее хранилище
   - Используется S3, permanent storage или временные сервисы
   - Файл доступен через внешний URL

## Рекомендации

### Если у вас Free Plan:

```bash
NOTION_DIRECT_UPLOAD_LIMIT_MB=5.0  # Не меняйте!
NOTION_TEMP_STORAGE=s3_public      # Для больших файлов
```

**Преимущества**:
- Маленькие файлы (≤ 5 MB) загружаются напрямую в Notion
- Большие файлы автоматически идут в S3
- Все работает автоматически

### Если у вас Paid Plan:

```bash
NOTION_DIRECT_UPLOAD_LIMIT_MB=100.0  # Или больше, до 5000
NOTION_TEMP_STORAGE=auto             # Fallback для очень больших файлов
```

**Преимущества**:
- Большинство PDF статей (обычно 1-50 MB) загружаются напрямую в Notion
- Очень большие файлы (> 5 GB) используют внешнее хранилище
- Максимальная простота и надежность

## Проверка вашего тарифа

Чтобы узнать, какой у вас тариф:
1. Откройте Notion
2. Перейдите в Settings & Members
3. Посмотрите раздел "Plan"

Или попробуйте загрузить файл 6 MB - если получите ошибку, значит у вас Free Plan.

## Troubleshooting

### Ошибка "File too large" при загрузке файла 6 MB

**Причина**: У вас Free Plan (лимит 5 MB)

**Решение**: 
- Это нормально! Система автоматически использует внешнее хранилище
- Или обновитесь до Paid Plan для загрузки больших файлов

### Хочу загружать файлы > 5 MB напрямую в Notion

**Решение**: 
1. Обновитесь до Paid Plan (Plus, Business или Enterprise)
2. Увеличьте лимит: `NOTION_DIRECT_UPLOAD_LIMIT_MB=100.0` (или больше)

### Как узнать, используется ли прямая загрузка?

**Проверьте логи**:
- Если видите "Successfully uploaded ... to Notion (ID: ...)" - используется прямая загрузка
- Если видите "Using external storage for ..." - используется внешнее хранилище
