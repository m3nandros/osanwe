# Проверка рабочего процесса загрузки PDF в Notion

## ✅ Полный поток работы

### 1. Пользователь запускает перевод через Discord:
```
/rosetta 1706.03762
```

### 2. Система генерирует PDF файлы локально:
- ✅ `temp/1706.03762/1706.03762_original.pdf` - оригинальный PDF
- ✅ `temp/1706.03762/source/translated.pdf` - переведенный PDF

### 3. Файлы отправляются пользователю в Discord:
- ✅ Пользователь получает оба PDF файла в Discord
- ✅ Это работает независимо от Notion

### 4. Параллельно файлы загружаются в Notion:

#### Шаг 4.1: Создание страницы в Notion
- ✅ Вызывается `notion_client.create_translation_page()`
- ✅ Передаются локальные пути к PDF файлам
- ✅ Создается страница с метаданными (название, авторы, резюме и т.д.)

#### Шаг 4.2: Загрузка PDF файлов
- ✅ Вызывается `_upload_pdfs_to_page()` с локальными путями
- ✅ Для каждого файла вызывается `_add_local_pdf_block()`

#### Шаг 4.3: Выбор метода загрузки

**Для файлов ≤ 5 MB:**
1. ✅ Пытается прямая загрузка через `_upload_file_to_notion_direct()`
2. ✅ Если успешно - файл загружается напрямую в Notion
3. ✅ Создается блок с типом `file_upload`

**Для файлов > 5 MB или если прямая загрузка не удалась:**
1. ✅ Автоматический fallback на внешнее хранилище
2. ✅ Используется `_upload_to_temporary_storage()` или `_save_to_permanent_storage()`
3. ✅ Создается блок с типом `external` и URL файла

### 5. Результат:
- ✅ Страница создана в Notion
- ✅ PDF файлы добавлены на страницу
- ✅ Файлы доступны вашей команде
- ✅ Долгосрочное хранение (10+ лет)

## 📋 Что произойдет при следующем переводе

1. **Перевод завершится** → PDF файлы будут созданы локально
2. **Файлы отправятся в Discord** → Пользователь получит их
3. **Страница создастся в Notion** → С метаданными статьи
4. **PDF файлы загрузятся в Notion**:
   - Если файлы ≤ 5 MB → Прямая загрузка в Notion
   - Если файлы > 5 MB → Внешнее хранилище (S3/permanent)

## ⚠️ Важные моменты

### Если файлы > 5 MB:

Система автоматически использует внешнее хранилище. Для этого нужно настроить:

**Вариант 1: AWS S3 (рекомендуется для долгосрочного хранения)**
```bash
NOTION_TEMP_STORAGE=s3_public
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret
AWS_S3_BUCKET=your-bucket
```

**Вариант 2: Постоянное локальное хранилище**
```bash
NOTION_TEMP_STORAGE=permanent
PERMANENT_STORAGE_URL_BASE=https://files.yourdomain.com/permanent_storage
```

### Если файлы ≤ 5 MB:

✅ Все работает автоматически! Файлы загрузятся напрямую в Notion.

## 🧪 Как проверить, что все работает

1. Запустите перевод через Discord: `/rosetta <arxiv_id>`
2. Дождитесь завершения перевода
3. Проверьте Notion:
   - Откройте созданную страницу
   - Должна быть секция "PDF Файлы"
   - Должны быть два файла: оригинальный и переведенный

## 📊 Логи для отладки

Если что-то не работает, проверьте логи:

```bash
tail -f logs/rosetta.log
```

Ищите сообщения:
- `"Successfully uploaded ... to Notion (ID: ...)"` - прямая загрузка успешна
- `"Using external storage for ..."` - используется внешнее хранилище
- `"Added local PDF ... to page via ..."` - файл добавлен на страницу
