# Варианты решения проблемы загрузки PDF в Notion

## Почему Discord URL не работают напрямую в Notion?

Есть несколько технических причин, почему Discord CDN URL могут не работать в Notion:

1. **Авторизация**: Discord CDN может требовать специальные заголовки авторизации или cookies
2. **Блокировка доменов**: Notion API может блокировать определенные домены (например, `cdn.discordapp.com`) из соображений безопасности
3. **CORS политики**: Браузерные политики безопасности могут блокировать доступ к Discord CDN
4. **Временность URL**: Discord URL могут быть временными или иметь ограничения по времени доступа
5. **Ограничения доступа**: Discord может ограничивать доступ к файлам только для авторизованных пользователей

## Реализованные решения

### 1. Автоматический режим (по умолчанию) - `auto`

**Как работает:**
- Сначала пытается использовать Discord CDN URL (если доступны)
- Если Discord URL не работают или недоступны, автоматически загружает файлы в временное хранилище
- Использует несколько сервисов по очереди для надежности

**Настройка:**
```bash
NOTION_FILE_UPLOAD_STRATEGY=auto
NOTION_TEMP_STORAGE=auto  # Пробует все сервисы по очереди
```

### 2. Только временное хранилище - `temporary`

**Как работает:**
- Игнорирует Discord URL
- Всегда загружает файлы в временное хранилище
- Гарантирует, что файлы будут доступны в Notion

**Настройка:**
```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=auto  # или transfersh, 0x0, fileio
```

### 3. Только Discord URL - `discord_only`

**Как работает:**
- Использует только Discord URL
- Не пытается загружать в временное хранилище
- Быстрее, но может не работать, если Notion блокирует Discord CDN

**Настройка:**
```bash
NOTION_FILE_UPLOAD_STRATEGY=discord_only
```

## Доступные хранилища

### Приватные хранилища (для конфиденциальных файлов)

#### 1. AWS S3 (приватное) ⭐
- **Лимит**: Зависит от вашего AWS аккаунта
- **Срок хранения**: Постоянно (или по настройке bucket)
- **Безопасность**: ✅ Приватное, presigned URL с ограниченным временем
- **Особенности**: Полный контроль, можно настроить политики доступа
- **Настройка**: `NOTION_TEMP_STORAGE=s3`
- **Требования**: AWS аккаунт, boto3 (`pip install boto3`)
- **⚠️ URL истекают** через заданное время (по умолчанию 7 дней)

#### 2. AWS S3 (публичное, постоянное) ⭐⭐⭐ ДЛЯ ДОЛГОСРОЧНОГО ХРАНЕНИЯ
- **Лимит**: Зависит от вашего AWS аккаунта
- **Срок хранения**: **Постоянно (10+ лет)**
- **Безопасность**: ⚠️ Публичные URL (можно ограничить через bucket policy)
- **Особенности**: **Постоянные URL, которые не истекают**
- **Настройка**: `NOTION_TEMP_STORAGE=s3_public`
- **Требования**: AWS аккаунт, boto3 (`pip install boto3`)
- **✅ РЕКОМЕНДУЕТСЯ для долгосрочного хранения (10+ лет)**

#### 3. Постоянное локальное хранилище ⭐⭐ ДЛЯ ДОЛГОСРОЧНОГО ХРАНЕНИЯ
- **Лимит**: Размер диска сервера
- **Срок хранения**: **Постоянно (10+ лет)**
- **Безопасность**: ✅ Файлы хранятся локально, можно настроить авторизацию
- **Особенности**: **Постоянные URL через веб-сервер**
- **Настройка**: `NOTION_TEMP_STORAGE=permanent`
- **Требования**: Веб-сервер (nginx/apache), настройка PERMANENT_STORAGE_URL_BASE
- **✅ РЕКОМЕНДУЕТСЯ для долгосрочного хранения с полным контролем**

#### 4. Локальное хранение (без публичных URL)
- **Лимит**: Размер диска сервера
- **Срок хранения**: Постоянно
- **Безопасность**: ✅ Файлы не покидают сервер, нет публичных URL
- **Особенности**: Файлы доступны только через ваш сервер
- **Настройка**: `NOTION_TEMP_STORAGE=local`

### Публичные временные хранилища (⚠️ НЕ для конфиденциальных файлов)

#### 1. transfer.sh
- **Лимит**: 10 GB
- **Срок хранения**: 14 дней
- **Безопасность**: ⚠️ Публичные URL - любой может скачать
- **Особенности**: Самый надежный из публичных, большой лимит
- **Настройка**: `NOTION_TEMP_STORAGE=transfersh`

#### 2. 0x0.st
- **Лимит**: 512 MB
- **Срок хранения**: 30 дней или до первого скачивания
- **Безопасность**: ⚠️ Публичные URL - любой может скачать
- **Особенности**: Хороший баланс между размером и сроком хранения
- **Настройка**: `NOTION_TEMP_STORAGE=0x0`

#### 3. file.io
- **Лимит**: 100 MB
- **Срок хранения**: 14 дней или до первого скачивания
- **Безопасность**: ⚠️ Публичные URL - любой может скачать
- **Особенности**: Простой, но меньший лимит
- **Настройка**: `NOTION_TEMP_STORAGE=fileio`

## Альтернативные решения (не реализованы)

### 1. Постоянное облачное хранилище

Можно настроить интеграцию с постоянными хранилищами:

**Google Drive:**
- Требует OAuth авторизацию
- Нужен Google API ключ
- Файлы хранятся постоянно
- Можно настроить публичный доступ

**AWS S3 / Cloudflare R2:**
- Требует API ключи
- Платно, но очень надежно
- Можно настроить CDN
- Файлы хранятся постоянно

**Dropbox:**
- Требует OAuth авторизацию
- Нужен Dropbox API ключ
- Файлы хранятся постоянно

### 2. Собственный файловый сервер

Можно развернуть собственный сервер для хостинга файлов:
- Полный контроль над файлами
- Нет ограничений по размеру
- Файлы хранятся постоянно
- Требует инфраструктуру (VPS, домен, SSL)

### 3. Прямая загрузка через Notion API

К сожалению, Notion API **не поддерживает** прямую загрузку файлов. Можно только:
- Использовать внешние URL (через file blocks)
- Загружать файлы вручную через UI Notion

## ⚠️ ВАЖНО: Безопасность и конфиденциальность

### Проблема с публичными хранилищами

**ВНИМАНИЕ**: Публичные временные хранилища (file.io, transfer.sh, 0x0.st) создают **публичные URL**, которые может скачать **любой, у кого есть ссылка**!

Если ваши PDF файлы содержат конфиденциальную информацию:
- ❌ **НЕ используйте** публичные временные хранилища
- ✅ Используйте **приватное хранилище** (AWS S3) или **локальное хранение**

### Варианты для конфиденциальных файлов

#### 1. AWS S3 с приватными bucket'ами (РЕКОМЕНДУЕТСЯ для приватности)

**Как работает:**
- Файлы загружаются в **приватный** AWS S3 bucket
- Генерируются **presigned URL** (временные приватные ссылки)
- Ссылки работают только ограниченное время (по умолчанию 7 дней)
- Файлы **недоступны** без presigned URL

**Настройка:**
```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=s3

# AWS S3 настройки
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
AWS_S3_BUCKET=your-bucket-name
AWS_S3_REGION=us-east-1
AWS_S3_PRESIGNED_URL_EXPIRY=604800  # 7 дней (в секундах)
```

**Требования:**
- AWS аккаунт
- S3 bucket (создайте приватный bucket)
- Установите boto3: `pip install boto3`

**Безопасность:**
- ✅ Файлы хранятся в приватном bucket
- ✅ Доступ только через presigned URL
- ✅ URL истекают через заданное время
- ✅ Можно настроить политики доступа на уровне bucket

#### 2. Локальное хранение (без публичных URL)

**Как работает:**
- Файлы **не загружаются** в публичные хранилища
- В Notion создается текстовая ссылка на локальный файл
- Файлы остаются на вашем сервере
- Доступ только через ваш сервер/бот

**Настройка:**
```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=local
```

**Безопасность:**
- ✅ Файлы не покидают ваш сервер
- ✅ Нет публичных URL
- ⚠️ Файлы доступны только через ваш сервер
- ⚠️ Нужно настроить доступ к файлам через ваш сервер

## Рекомендации

### Для долгосрочного хранения (10+ лет) (РЕКОМЕНДУЕТСЯ):
```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=s3_public
```

Это обеспечит:
- ✅ Постоянные URL (не истекают)
- ✅ Долгосрочное хранение (10+ лет)
- ✅ Высокая надежность (AWS S3)
- ✅ Низкая стоимость (~$0.12/месяц за 5 GB)

**Альтернатива (локальное хранилище):**
```bash
NOTION_TEMP_STORAGE=permanent
PERMANENT_STORAGE_URL_BASE=https://files.yourdomain.com/permanent_storage
```

### Для конфиденциальных файлов:
```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=s3
```

Это обеспечит:
- ✅ Приватное хранение в AWS S3
- ✅ Временные приватные ссылки (истекают через 7 дней)
- ✅ Контроль доступа
- ✅ Файлы недоступны публично
- ⚠️ **URL истекают** - не подходит для долгосрочного хранения

### Для большинства случаев (не конфиденциальные файлы):
```bash
NOTION_FILE_UPLOAD_STRATEGY=auto
NOTION_TEMP_STORAGE=auto
```

Это обеспечит:
- Попытку использовать Discord URL (быстро, если работает)
- Автоматический fallback на временное хранилище (надежно)
- Использование лучшего доступного сервиса

### Если Discord URL не работают:
```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=transfersh
```

Это гарантирует:
- Все файлы будут доступны в Notion
- Использование самого надежного сервиса (transfer.sh)
- Большой лимит размера файла (10 GB)
- ⚠️ **Публичные URL** - любой может скачать, если знает ссылку

### Если нужна максимальная скорость:
```bash
NOTION_FILE_UPLOAD_STRATEGY=discord_only
```

Это:
- Использует только Discord URL
- Не делает дополнительных загрузок
- Может не работать, если Notion блокирует Discord CDN

## Настройка в .env файле

Добавьте в ваш `.env` файл:

### Для приватного хранения (рекомендуется для конфиденциальных файлов):
```bash
# Стратегия загрузки файлов (auto, temporary, discord_only)
NOTION_FILE_UPLOAD_STRATEGY=temporary

# Приватное хранилище AWS S3
NOTION_TEMP_STORAGE=s3

# AWS S3 настройки
AWS_ACCESS_KEY_ID=your_access_key_here
AWS_SECRET_ACCESS_KEY=your_secret_key_here
AWS_S3_BUCKET=your-bucket-name
AWS_S3_REGION=us-east-1
AWS_S3_PRESIGNED_URL_EXPIRY=604800  # 7 дней в секундах
```

### Для публичного хранения (не конфиденциальные файлы):
```bash
# Стратегия загрузки файлов (auto, temporary, discord_only)
NOTION_FILE_UPLOAD_STRATEGY=auto

# Предпочтительный сервис временного хранилища (auto, transfersh, 0x0, fileio, s3, local)
NOTION_TEMP_STORAGE=auto
```

### Для локального хранения (без публичных URL):
```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=local
```

## Отладка

Если файлы не загружаются в Notion:

1. Проверьте логи - они покажут, какой метод используется
2. Проверьте настройки в `.env` файле
3. Попробуйте изменить стратегию на `temporary`
4. Проверьте размер файлов (не превышают ли лимиты)
