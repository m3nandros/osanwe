# Прямая загрузка файлов в Notion (новый API, май 2025)

## 🎉 Отличная новость!

Notion API теперь поддерживает **прямую загрузку файлов** без промежуточных хранилищ!

## Как это работает

Система автоматически использует новый API Notion (`v1/file_uploads`) для прямой загрузки PDF файлов:

1. **Файлы ≤ 5 MB** (Free Plan limit): Загружаются **напрямую в Notion** через новый API
2. **Файлы > 5 MB**: Используется внешнее хранилище (S3, permanent и т.д.)

**Примечание**: Если у вас Paid Plan, можно увеличить лимит через `NOTION_DIRECT_UPLOAD_LIMIT_MB` (до 5 GB).

## Преимущества

✅ **Прямая загрузка** - файлы идут напрямую с вашего сервера в Notion  
✅ **Долгосрочное хранение** - файлы хранятся на серверах Notion (AWS S3)  
✅ **Безопасность** - файлы подчиняются правам доступа вашей страницы  
✅ **Простота** - не нужны промежуточные хранилища для небольших файлов  
✅ **Надежность** - файлы доступны вашей команде навсегда  

## Процесс загрузки

### Для файлов ≤ 5 MB (Free Plan) или ≤ лимита (Paid Plans):

1. **Инициализация**: Создается объект загрузки в Notion
2. **Загрузка**: Файл загружается напрямую в Notion
3. **Прикрепление**: Файл автоматически прикрепляется к странице

### Для файлов > лимита:

1. Файл загружается во внешнее хранилище (S3, permanent и т.д.)
2. Создается ссылка на файл
3. Ссылка добавляется в Notion как external file block

## Настройка

### Рекомендуемая настройка (автоматический выбор):

```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=auto
```

Это обеспечит:
- Прямую загрузку в Notion для файлов ≤ 5 MB (Free Plan) или до лимита (Paid Plans)
- Автоматический fallback на внешнее хранилище для больших файлов

### Для долгосрочного хранения больших файлов:

```bash
NOTION_FILE_UPLOAD_STRATEGY=temporary
NOTION_TEMP_STORAGE=s3_public  # или permanent
```

## Ограничения по тарифам Notion

### Free Plan (Бесплатный):
- **Максимум 5 MB** на один файл
- Если файл больше 5 MB, система автоматически использует внешнее хранилище

### Paid Plans (Plus, Business, Enterprise):
- **До 5 GB** на один файл
- Можно увеличить лимит через `NOTION_DIRECT_UPLOAD_LIMIT_MB` в `.env`

### Настройка лимита:

```bash
# Для Free Plan (по умолчанию)
NOTION_DIRECT_UPLOAD_LIMIT_MB=5.0

# Для Paid Plans (можно увеличить)
NOTION_DIRECT_UPLOAD_LIMIT_MB=100.0  # или больше, до 5000 (5 GB)
```

**Важно**: Если вы используете Free Plan, не меняйте лимит - файлы > 5 MB будут отклонены API.

## Что изменилось

### Раньше:
- Все файлы загружались во внешние хранилища (S3, file.io и т.д.)
- Создавались внешние URL
- URL добавлялись в Notion как external file blocks

### Теперь:
- Файлы ≤ 20 MB загружаются **напрямую в Notion**
- Файлы > 20 MB используют внешнее хранилище (как раньше)
- Автоматический выбор метода в зависимости от размера

## Технические детали

### Новый API Notion:

**Endpoint**: `POST /v1/file_uploads`

**Процесс**:
1. Инициализация: `POST /v1/file_uploads` с метаданными файла
2. Загрузка: `PUT` на полученный URL с бинарными данными
3. Прикрепление: Использование `file_upload_id` в блоке

### Тип блока:

**Старый способ** (external URL):
```json
{
  "type": "file",
  "file": {
    "type": "external",
    "external": {"url": "https://..."}
  }
}
```

**Новый способ** (direct upload):
```json
{
  "type": "file",
  "file": {
    "type": "file_upload",
    "file_upload": {"id": "file_upload_id"}
  }
}
```

## Troubleshooting

### Файлы не загружаются напрямую

**Проверьте**:
1. Размер файла (должен быть ≤ 5 MB для Free Plan, или ≤ лимита для Paid Plans)
2. Ваш тариф Notion (Free Plan имеет лимит 5 MB)
3. Логи - возможно, используется fallback на внешнее хранилище
4. Версия Notion API (должна поддерживать v1/file_uploads)

**Решение**: Если файл > 5 MB на Free Plan, система автоматически использует внешнее хранилище. Это нормально.

### Ошибка "Failed to initialize file upload"

**Возможные причины**:
- Неправильный API токен
- Файл слишком большой (> 20 MB)
- Проблемы с сетью

**Решение**: Система автоматически использует fallback на внешнее хранилище

### Файлы загружаются, но не отображаются

**Проверьте**:
1. Логи - возможно, ошибка при прикреплении блока
2. Права доступа к странице в Notion
3. Размер файла (возможно, превышает лимит)

## Миграция

Если у вас уже есть файлы во внешних хранилищах, они продолжат работать. Новые файлы будут загружаться напрямую в Notion (если ≤ 20 MB).
