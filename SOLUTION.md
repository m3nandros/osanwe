# Решение проблемы с загрузкой PDF в Notion

## Проблема

PDF файлы не загружаются в Notion, создаются только текстовые ссылки.

## Причины

1. **Прямая загрузка в Notion не работает**: API возвращает ошибку 400 "Invalid request URL"
   - Возможно, API `/v1/file_uploads` еще не доступен в вашем аккаунте
   - Или формат запроса неправильный

2. **Временные хранилища не работают**: transfer.sh, 0x0.st, file.io недоступны или заблокированы

## Решение

### Вариант 1: Настроить AWS S3 (рекомендуется)

Это обеспечит надежное долгосрочное хранение файлов.

1. **Создайте S3 bucket** (если еще нет):
   - Зайдите в AWS Console
   - Создайте bucket в регионе (например, `us-east-1`)
   - Настройте публичный доступ (если нужен) или используйте presigned URLs

2. **Настройте переменные окружения** в `.env`:
   ```bash
   NOTION_TEMP_STORAGE=s3_public
   AWS_ACCESS_KEY_ID=your_access_key
   AWS_SECRET_ACCESS_KEY=your_secret_key
   AWS_S3_BUCKET=your-bucket-name
   AWS_S3_REGION=us-east-1
   AWS_S3_PUBLIC_ACCESS=true  # для публичных URL
   ```

3. **Перезапустите Discord бота**

### Вариант 2: Настроить постоянное локальное хранилище

Если у вас есть веб-сервер, можно использовать локальное хранилище.

1. **Настройте переменные окружения** в `.env`:
   ```bash
   NOTION_TEMP_STORAGE=permanent
   PERMANENT_STORAGE_DIR=/path/to/permanent/storage
   PERMANENT_STORAGE_URL_BASE=https://files.yourdomain.com/permanent_storage
   ```

2. **Настройте веб-сервер** для доступа к файлам

3. **Перезапустите Discord бота**

### Вариант 3: Исправить прямую загрузку в Notion (если API доступен)

Если у вас Paid Plan Notion и API должен работать, возможно, проблема в формате запроса.

Проверьте:
1. Ваш тариф Notion (Free Plan имеет лимит 5 MB)
2. Доступность API `/v1/file_uploads` в вашем аккаунте
3. Формат запроса (может потребоваться обновление)

## Проверка

После настройки:

1. **Запустите тест**:
   ```bash
   python3 test_notion_upload_debug.py
   ```

2. **Проверьте логи** - должны быть сообщения:
   - `"Successfully uploaded ... to Notion"` - прямая загрузка
   - `"Added local PDF ... to page via S3 public"` - S3 загрузка
   - `"Added local PDF ... to page via permanent"` - локальное хранилище

3. **Запустите новый перевод** через Discord бота

4. **Проверьте Notion** - должны быть файловые блоки, а не текстовые ссылки

## Рекомендация

**Используйте AWS S3** (`s3_public`) - это самое надежное решение:
- ✅ Долгосрочное хранение (10+ лет)
- ✅ Надежность
- ✅ Контроль доступа
- ✅ Масштабируемость

## Быстрая настройка S3

1. Создайте bucket в AWS S3
2. Настройте публичный доступ (или используйте presigned URLs)
3. Добавьте переменные в `.env`
4. Перезапустите бота

После этого все PDF файлы будут автоматически загружаться в S3 и добавляться в Notion как внешние файлы.
